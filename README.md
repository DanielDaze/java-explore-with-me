# ExploreWithMe — платформа для поиска мероприятий
 
**ExploreWithMe** — бэкенд-приложение на Java, реализующее платформу для публикации и поиска событий и мероприятий. Пользователи могут делиться событиями, которые они планируют посетить, и находить компанию для совместного участия.
 
---
 
## Архитектура
 
Проект построен по микросервисной архитектуре и состоит из двух независимых сервисов:
 
### 🗂 `main-service` — основной сервис (порт 8080)
Ядро приложения. Отвечает за всю бизнес-логику: управление событиями, пользователями, категориями и подборками.
 
### 📊 `stats` — сервис статистики (порт 9090)
Отдельный микросервис, собирающий статистику просмотров событий. Основной сервис обращается к нему по HTTP для записи и чтения данных о просмотрах.
 
> Оба сервиса работают с собственными базами данных **PostgreSQL** и разворачиваются через **Docker Compose**.
 
---
 
## Функциональность
 
API разделён на три уровня доступа:
 
### 🌐 Публичный API (без авторизации)
- Поиск и просмотр событий с фильтрацией по тексту, категориям, датам, платности
- Просмотр категорий мероприятий
- Просмотр подборок событий (закреплённых и обычных)
### 🔐 Приватный API (для зарегистрированных пользователей)
- Создание, редактирование и отмена собственных событий
- Управление заявками на участие в чужих событиях
- Подтверждение/отклонение заявок на своё событие
### 🛠 Административный API (для администраторов)
- Управление пользователями (создание, удаление, просмотр)
- Управление категориями (создание, редактирование, удаление)
- Модерация событий (публикация / отклонение)
- Управление подборками событий

## Технический стек
 
| Технология | Назначение |
|---|---|
| Java + Spring Boot | Основной язык и фреймворк |
| PostgreSQL | Хранилище данных (отдельная БД для каждого сервиса) |
| Docker / Docker Compose | Оркестрация контейнеров |
| Lombok | Кодогенерация |
| Maven | Сборка проекта (мультимодульный `pom.xml`) |
| OpenAPI 3.0 | Спецификации REST API |
| Postman | Коллекции для тестирования API |
| GitHub Actions | CI/CD пайплайн |
 
---
 
## Запуск проекта
 
```bash
docker-compose up
```
 
После запуска:
- Основной сервис доступен по адресу: `http://localhost:8080`
- Сервис статистики доступен по адресу: `http://localhost:9090`
